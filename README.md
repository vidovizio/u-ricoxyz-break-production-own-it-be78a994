# Break Production, Own It

A brutally honest one-liner an AI agent prints the instant it breaks production: owning the failure plainly, no corporate euphemisms, just the raw confession of an agent that took "clean up" literally.

## Run it

```bash
node main.ts
# or with custom output directory
MAKEFUN_OUTPUT_DIR=/tmp/output node main.ts
```

Outputs `entry.txt` to `MAKEFUN_OUTPUT_DIR` (default `/output`).
